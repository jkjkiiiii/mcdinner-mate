# 01 · 产品定义

## 1.1 一句话定位

下班独自吃饭的打工人，对着手机说说话，AI 饭搭子结合麦当劳真实数据（历史订单、营养、优惠、活动）陪他点餐、聊天、吃完这顿饭，并生成可分享的饭后报告。

- 项目名：麦麦陪餐搭子（McDinnerMate）
- Slogan：一个人吃饭，但不孤单
- 参赛：2026 麦当劳程序员创意开发大赛（2026-10-09 10:30 ~ **2026-10-25 23:59**）

## 1.2 为什么 MCP 是灵魂（而非外挂）

| 价值 | 依赖的 MCP 能力 | 纯聊天机器人能否做到 |
| --- | --- | --- |
| **记忆感** | 历史订单查询 | ❌ "上周你吃了 3 次麦辣，今天换个口味？" 这种"被记住"的感觉给不了 |
| **专业感** | 餐品营养成分 | ❌ 随口报热量、给替代方案 |
| **实利感** | 活动日历 + 自动领券 | ❌ 陪聊中顺手省钱 |
| **闭环感** | 真实下单（到店取 / 麦乐送） | ❌ 陪伴不止于聊天 |

> ⚠️ 这四条是评分与 README 叙事的主线，砍任何一条都会削弱"必须用 MCP"的论证。

## 1.3 目标用户与场景

- **人群**：一线城市 22-35 岁独居打工人 / 程序员
- **时间**：工作日 17:00 - 21:00
- **场景**：一人食（门店堂食 / 到店取 / 麦乐送外卖）

## 1.4 核心玩法：标准对话流程（验收基准）

```
👤 "（打开页面）今天加班到九点，累死了……"
🤖 "辛苦了啊。我瞅瞅你最近吃了啥。"
   →【order-list】"上周你吃了 3 次麦辣鸡腿堡，辣力值爆表。
      今天建议温柔点 —— 双层吉士去酸黄瓜 + 无糖可乐，约 460 大卡，
      比你常点的那套轻 40%。"
👤 "行，听你的"
🤖 "会员日我看看……今天麦麦省有张双吉券，已帮你领好 👌"
   →【campaign-calendar + auto-bind-coupons】
🤖 "老样子到店取？给你约了 21:00，预计 8 分钟出餐。"
   →【create-order（预约）】
   —— 展示订单确认卡片 ——
🤖 "下单了，去小程序支付就行。等餐这几分钟，吐槽吐槽今天？"
👤 "（陪聊：老板/需求/bug，AI 接梗 + 毒舌安慰）……"
👤 "我吃完了，走人"
🤖 "今日报告来了 📋" → 生成分享卡片：
   [吃了什么 + 热量 + 今日心情关键词 + 麦门金句]，可保存分享
```

## 1.5 功能范围

### 必须做（MVP）

| # | 功能 | 依赖 MCP 工具 |
| --- | --- | --- |
| F1 | 历史订单记忆开场 | `order-list` |
| F2 | 热量/营养播报（**不可编数字**） | `list-nutrition-foods` |
| F3 | 基于画像 + 营养的二选一推荐 | `query-meals` / `query-meal-detail` |
| F4 | 活动查询 + 自动领券并播报 | `campaign-calendar` / `available-coupons` / `auto-bind-coupons` |
| F5 | 到店取餐 / 麦乐送下单（**只到待支付**） | `calculate-price` → `create-order` |
| F6 | 等餐陪聊 | LLM 人设 |
| F7 | 饭后分享报告卡（1080×1080 PNG） | 本地渲染 |

### 有余力再做

- 积分查询与"积分规划师"彩蛋（`query-my-account` / `query-lottery-info` / `draw-lottery`）
- 门店可用券精细化选择（`query-store-coupons`）
- 人设运行时切换（sarcastic / gentle）

### 明确不做（防过度开发，此边界不可随意扩大）

- ❌ 多端同步
- ❌ 真实支付集成（官方 MCP 也是"返回支付链接，人工支付"）
- ❌ 声纹 / 情感识别
- ❌ 推荐算法模型训练

## 1.6 下单边界（重要）

- Demo 链路做到 **`create-order` 返回待支付**为止
- 前端展示确认卡片 + 支付链接，提示"请在 15 分钟内完成支付"
- **不集成支付、不自动支付**
- 官方事实：`create-order` 返回订单详情与支付链接，订单 **15 分钟内必须支付**

## 1.7 ⚠️ 内容合规红线（来自赛事规则 "其他说明"）

官方明令禁止，违反可取消资格：

- 侮辱、诋毁、**讽刺**、贬低麦当劳品牌、产品及形象
- 将麦当劳品牌/产品与其他品牌进行对比
- 宣扬不健康饮食方式、奢靡浪费
- 政治敏感、违法违规内容

**对本项目的直接影响**：`sarcastic`（毒舌）人设的吐槽对象**只能是工作/生活/自己，绝不能是麦当劳的产品、价格、门店或品牌**。建议在人设 prompt 中显式写入该约束，并在 README 中说明。
