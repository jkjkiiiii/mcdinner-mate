# 08 · 验收测试用例

> Demo 前必须**重启服务清缓存后完整跑一遍**。

| # | 用户操作/话术 | 预期 | 关联风险 |
| --- | --- | --- | --- |
| 1 | 打开页面说"今天加班好累" | 查出历史订单并提及（"上周你吃了 3 次麦辣…"），语音 + 字幕 | R3（ASR） |
| 2 | "这个多少卡" | 引用 `list-nutrition-foods` 数据口播，**误差为 0（不可编数字）** | R7（toon 格式） |
| 3 | "最近有啥活动" | 列出活动日历；说"都领了"后执行 `auto-bind-coupons` 并播报结果 | — |
| 4 | "就这个吧，老样子到店取" | 创建待支付订单 + 确认卡片（**金额与官方一致，注意单位是分**） | R8（单位） |
| 5 | 播放中抢话"别说了" | TTS 立即停止并听用户说 | R-barge-in |
| 6 | "我吃完了" | 生成并展示分享报告卡（1080×1080 PNG） | — |
| 7 | 断网恢复后重说 | 兜底话术 + 重试成功，不崩溃 | R5 |
| 8 | 连续对话 5 分钟 | 无 429/401，缓存生效 | R9（限流） |
