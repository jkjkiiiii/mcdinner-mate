## 9.4 内容合规红线（可直接导致取消资格）

禁止出现：

- a) 违反中国法律法规、有损国家尊严或利益、妨碍社会安定、违反公序良俗
- b) 政治敏感内容
- c) 宣扬淫秽色情赌博迷信恐怖暴力、**不健康饮食方式**、奢靡浪费、拜金主义
- d) 伤害任何群体情感、损害麦当劳名声
- e) **侮辱、诋毁、讽刺、贬低麦当劳品牌、产品及形象**；或将麦当劳与**其他品牌对比**
- f) 侵害第三方知识产权、隐私、商业秘密
- g) 引发重大负面舆论
- h) 恶意脚本、钓鱼链接、病毒

### 对本项目的影响

1. `sarcastic` 人设的吐槽对象**只能是工作/生活/自己**
2. README 与 Demo 中**不得出现与其他快餐品牌的对比**
3. 注意不要写成"鼓励多吃快餐"，叙事应落在"陪伴 / 情绪价值"，营养功能用于**知情选择**而非劝食
4. GitHub 账号昵称、头像、简介同样受约束
