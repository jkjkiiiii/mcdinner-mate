## 2. 设计内核

**物理上只有一个人，但有一束"对话的光"证明他并不孤单。**

关键判断：**本产品的主角是「饭搭子」，不是「吃饭的人」。** 用户是代入方，不是被观看的对象。
画面里真正该被看见的是那个"陪伴的存在"——而它没有实体，只有声音与对话气泡。

由此确定吉祥物路线：**轻量吉祥物（光团子）**，而非真人、手部剪影或纯空场景。

## 4. 吉祥物「光团子」规格

> 命名待定（建议：中文「搭子」/ 英文 `Dinna`；**避免任何"麦X"命名**，有商标嫌疑）

### 设计约束

形状必须极简到**可被稳定复现**——无论是 SVG、PIL 重绘还是后续任何再创作。

| 要素 | 设定 |
| --- | --- |
| 形态 | 圆润的一小团，像"一团暖光"，也像一盏小夜灯 |
| 唯一记忆点 | 头顶一缕卷曲暖光 + 顶端小圆（既像热汤热气，也像刚飘出的对话气泡） |
| 面部 | 两道浅弧线眼（U 形），**没有嘴** —— 克制、安静，正是 gentle 气质 |
| 底部 | 椭圆托盘，暗示"陪你吃饭" |
| 状态 | 静态温润；「说话中」= 呼吸式泛光 |

### 几何（`viewBox 0 0 200 220`，背景透明）

| 部件 | 坐标 |
| --- | --- |
| 光晕椭圆 | `cx=100 cy=130 rx=96 ry=88` |
| 头顶卷曲 | 三次贝塞尔 `M100 50 C 86 38, 114 32, 100 18`，描边宽 5 |
| 顶端小圆 | `cx=100 cy=13 r=9` |
| 主体 | `M100 56 C143 56 173 87 173 127 C173 160 142 182 100 182 C58 182 27 160 27 127 C27 87 57 56 100 56 Z` |
| 高光椭圆 | `57,87 → 96,110`，白 alpha 95 |
| 眼 | 两道弧，bbox `[(cx∓13),113,(cx±13),133]`，`cx=85 / 115`，描边宽 6 |
| 腮红 | `50,135→72,147` 与 `128,135→150,147`，陶土色 alpha 92 |
| 托盘椭圆 | `cx=100 cy=186 rx=64 ry=12` |

### 色板

| 用途 | 色值 |
| --- | --- |
| 奶油白 | `#FFF6E2` |
| 暖黄（上） | `#FFE3AE` |
| 主体暖黄（下） | `#FFCE7A` |
| 光晕 | `#FFC96B` |
| 陶土暖橙（点缀/腮红/托盘） | `#E8925C` / `#D97A48` |
| 眼（暖棕） | `#8A5A2B` |

> ⚠️ 色板**刻意避开麦当劳品牌红/黄**，用陶土暖橙做点缀，规避商标联想。

### 最小可用尺寸

32px（24px 偏糊，头像建议 ≥48px）。

定稿参数（对应用户自备背景 `archive/backgrounds/user_night_dinner.jpg`）：

| 参数 | 值 |

| `title_y` / `slog_y` / `sub_y` / `title_size` | `230` / `336` / `406` / `72` |

## 6. ⚠️ PIL 绘制吉祥物的三个坑（改代码前必读）

| 坑 | 现象 | 解法 |
| --- | --- | --- |
| `Image.radial_gradient` 未归一化 | 光晕层在自己矩形边界被硬切断（边长中点 alpha≈33，四角才是 0）→ **画面出现隐约方形虚框** | 自写归一化欧氏径向渐变，令 `d=1`（内切圆）处 alpha 恰为 0 |
| 直接按最终尺寸绘制 | 弧线/椭圆描边明显**锯齿** | **4× 超采样 + LANCZOS 降采样**（`draw_mascot(scale, ss=4)`） |
| 在 RGBA 图层用 `ImageDraw` 画半透明色 | Pillow **直接写入像素而非混合** → 高光/腮红把身体"挖穿"露背景（视觉上灰色斑块/黑点）；传 `Draw(im,"RGBA")` 也无效 | 高光/腮红画在**独立图层**，再 `layer.alpha_composite(ov)` 叠加 |
