## 1. 项目定位与目标用户

### 1.1 一句话定位

> **下班独自吃饭的打工人，对着手机说说话，AI 饭搭子结合麦当劳真实数据
> （历史订单、营养、优惠、活动）陪他点餐、聊天、吃完这顿饭，并生成可分享的饭后报告。**

### 1.2 定位的边界（**"是什么/不是什么"必须同时讲清**）

| ✅ 是 | ❌ 不是 |
| --- | --- |
| 陪伴型产品，**情绪价值优先** | 点餐效率工具 / 比价工具 |
| 有记忆的**长期关系**（记得你的口味历史） | 一次性问答式客服机器人 |
| 真实数据驱动（官方接口，可核对） | 靠人设话术"演"出记忆感 |
| 真实下单闭环（到「待支付」为止） | 支付工具（**不集成支付、不代付**） |
| 语音对话优先（本地 ASR + TTS） | 只支持打字的聊天框 |

> ⚠️ **对外表达最容易犯的错**：把它说成"麦当劳点餐助手"。
> 一旦被归到点餐助手，就和 100 多个竞品正面撞车了。**必须始终把"陪"放在"点"前面。**

### 1.3 目标用户

| 层级 | 人群 | 时间 | 场景 |
| --- | --- | --- | --- |
| **核心** | 一线城市 22–35 岁独居打工人 / 程序员 | 工作日 **17:00–21:00** | 一人食：门店堂食 / 到店取 / 麦乐送 |
| 次核心 | 独居的运营、设计、内容从业者 | 工作日午休 & 深夜加餐 | 情绪内耗需要出口 |
| 外围 | 出差频繁的商务、异地工作者 | 不固定 | 陌生城市的一个人吃饭 |

**共同特征**：经济上独立、社交上克制（**想要陪伴但不想社交**）、
对"被算法推荐"无感但吃"被记住"这一套。

## 2. 核心功能与差异化亮点

### 2.1 六大能力（每一条都对应真实的 MCP 工具）

| # | 能力 | 用户感知 | 依赖 |
| --- | --- | --- | --- |
| 1 | 🧠 **记忆感** | 开场第一句就提起你最近常点的东西 | `order-list` |
| 2 | 🥗 **专业感** | 随口报热量、给替代方案，**查不到就说查不到** | `list-nutrition-foods` |
| 3 | 🎟️ **实利感** | 陪聊时顺手查活动、把券领好 | `campaign-calendar` / `available-coupons` / `auto-bind-coupons` |
| 4 | ✅ **闭环感** | 真的帮你把单下好，**停在「待支付」** | `query-meals` → `calculate-price` → `create-order` |
| 5 | 💬 **陪伴感** | 等餐和吃饭时陪你吐槽老板、需求、bug | 本地大模型 + 人设 prompt |
| 6 | 📋 **仪式感** | 吃完生成一张可分享的饭后报告卡 | 本地渲染 1080×1080 |

### 2.2 三张差异化牌

**牌一 · 赛道差异（最重要）**
竞品集中在省钱 / 营养计算 / 积分 / 点餐效率。**「陪餐陪伴 / 情绪价值」赛道依旧稀缺。**
我们的主张：**别人优化"点完这顿饭要几步"，我们关心"这顿饭有没有人陪"。**

**牌二 · 真实性差异（可被验证）**
所有数字都来自官方接口，**一个都不编**；查不到就明说查不到。
甚至演示视频里每一句旁白都标注了真实推理耗时（20–134 秒/轮）——**我们加速剪辑，但不谎称秒回**。
> 这条是评审最容易验证、也最容易被同行戳穿的地方。**它既是卖点，也是护城河。**

**牌三 · 技术形态差异**
- **本地大模型 + 本地语音识别**：对话与语音不上云，**数据不出本机**
- **真实下单闭环**：不是"点个按钮弹个演示"，是真实账号下真实订单到「待支付」
- **MCP 的工具编排**：官方给了 35 个工具，我们**没有全量塞给模型**
  （实测会把 27B 模型压垮导致空回复），而是裁剪出 15 个并做了结果瘦身，
  把 5 轮 128 秒的算价链路优化到 3 轮 20 秒

### 2.3 明确不做（**主动划边界，体现克制**）

多端同步 · 真实支付 · 声纹 / 情感识别 · 推荐算法模型训练。

> 对外话术：「不做这些不是偷懒，是想在有限时间里把"陪伴"这一件事做扎实。」

## 3. 主要使用场景与典型痛点

### 3.1 痛点分层（**宣传片只打第三层，前两层是背景**）

| 层级 | 痛点 | 现有产品是否解决 |
| --- | --- | --- |
| 表层 | 点餐要跳好几步、凑单麻烦 | ✅ 已解决得很好了（所以没机会） |
| 中层 | 一个人不知道吃什么、选择困难 | 🔶 部分解决（推荐工具很多） |
| **深层** | **一个人吃饭，没人说话** | ❌ **几乎没人做** |

### 3.2 三个典型场景

**场景 A · 加班夜的收尾（主场景，宣传片首选）**
> 晚上九点走出写字楼，脑子还是白天那堆需求。想吃点热的，但不想思考；
> 想有人说句话，但不想社交。

- 触发语句：「今天加班到九点，累死了」
- 产品动作：先接情绪 → 提起上次点的 → 给二选一 → 算价 → 建单 → 陪等餐
- **为什么选它**：这个场景的孤独感最普世，且"深夜暖光"的视觉语言最好看

**场景 B · 周末一个人不想出门**
> 在家躺着，饿但不想动。点外卖的十分钟是空的。

- 触发语句：「懒得动了，点个外卖吧」
- 产品动作：走外送链路（地址已有），期间陪着聊天

**场景 C · 等餐/吃饭的空档**
> 餐还没好，或者一个人坐在店里不知道眼睛放哪。

- 触发语句：「我吃完了，走人」
- 产品动作：生成饭后报告卡，把一个人的饭变成一个可以被记住的瞬间

### 3.3 现有方案的失效点（**对比时只用这一句，不要点名竞品**）

现有工具在**"决策"**和**"执行"**上做得很好，但它们都止步于**订单创建完成的那一刻**——
而一个独自吃饭的人，最难熬的恰恰是**下单之后的等待**和**吃饭时的那二十分钟**。

## 4. 价值主张与预期收益

### 4.1 对用户（第一层，宣传片主打）

| 价值 | 具体表述 |
| --- | --- |
| **情绪价值** | 它记得你。被记住这件事，比被推荐更让人舒服 |
| **实用价值** | 真能省钱（顺手领券）、真能算准（官方算价）、真能下单（闭环到待支付） |
| **决策减负** | 不给你十个选项，只给二选一 + 一句为什么 |
| **体面** | 不催你、不评价你吃得多不多，也不假装它是人 |

### 4.2 对品牌侧（第二层，给评审看的）

> ⚠️ 以下为**逻辑推演，未经数据验证**，对外表达时必须标明是"预期"而非"实测"。

- 把「一个人吃饭」从**凑合一顿**变成**有仪式感的一顿** → 提升一人食场景的打开频率
- 让官方 App/Mini 程序的**数据资产（历史订单、营养、券）产生情感价值**，而不只是效率价值
- 是 MCP 能力的**示范性用法**：把 35 个原子工具编排成一个有"人格"的完整体验

### 4.3 一句话价值主张

> **它不只是帮你更快地点完这顿饭，它是陪你把这顿饭吃完。**

## 5. 品牌调性

### 5.1 内核

> **物理上只有一个人，但有一束「对话的光」证明他并不孤单。**

关键判断：**主角是「饭搭子」，不是「吃饭的人」。** 用户是代入方，不是被观看的对象。
画面里真正该被看见的，是那个"陪伴的存在"——而它没有实体，只有声音与对话气泡。

### 5.2 调性关键词

**安静 · 治愈 · 克制 · 暖 · 有分寸**

### 5.3 语气红线（**写文案时逐条对照**）

| ✅ 可以 | ❌ 绝对不要 |
| --- | --- |
| 接住情绪：「辛苦了啊」 | 卖惨：雨夜痛哭、醉汉、垃圾堆、自嘲孤独到病态 |
| 关心但不干涉：「饿了吧？」 | 说教：「这样吃不健康」「你应该……」 |
| 记得但不炫技：「你上次点的那套」 | 油腻：亲昵称呼、颜文字轰炸、土味情话 |
| 有一点点自嘲（可） | 评价餐品、价格、门店、品牌（**合规红线**） |
| 安静留白 | 密不透风的解说（旁白塞满全片） |

### 5.4 两套人设

- **`gentle`（默认，对外只用这套）**：温柔树洞。语气软，接得住情绪，不评判。
- `sarcastic`（可选，不用于宣传）：毒舌麦门信徒。**吐槽对象只能是工作 / 老板 / 需求变更 / bug /
  加班 / 通勤**，绝不吐槽麦当劳的餐品、价格、门店与品牌。

> **对外宣传一律用 `gentle`。** `sarcastic` 有合规风险，不值得为它冒风险。

### 5.5 视觉规范（已冻结，见 `docs/design/BANNER.md`）

| 项 | 规范 |
| --- | --- |
| 主色调 | 深夜蓝紫冷调（大面积） |
| 暖源 | 暖黄灯光 `#FFCE7A` |
| 点缀 | 陶土暖橙 `#E8925C`（**刻意避开麦当劳品牌红黄，规避商标联想**） |
| 暗色 UI | `#12141a`（产品界面本色） |
| 字体 | 微软雅黑 Bold / Regular |
| 吉祥物 | 「光团子」：一团暖光，**没有嘴**（克制、安静），头顶一缕卷曲暖光 |
| **禁止** | 任何品牌 Logo / 金色拱门「M」/ 可读品牌文字 / 带商标的包装 |
| **人脸** | 建议**不出现清晰正脸**（背影、侧影、逆光、低头、手部与局部） |

### 5.6 情绪表达的正确刻度

> **哀而不伤。** 孤独可以有，凄苦不要有。目标是让观众说"这说的就是我"，
> 而不是"好惨啊"。差别在于：**我们给的是陪伴，不是同情。**

## 6. 受众画像

> ⚠️ 以下为**合成画像**（基于目标用户定义构造的典型人物，非真实用户数据），
> 用途是让创作者"对着一个具体的人写"，而不是对着一个抽象人群写。

### 画像 A · 小周（核心受众，宣传片主角模板）

- 28 岁，后端工程师，北京，独居一居室
- 一天：9:30 上班 → 需求评审 → 改 bug → 20:30 才发现没吃饭 → 21:00 下班
- 手机里有两三个外卖 App，但他最常干的事是**在楼下便利店站两分钟又走开**
- 触发语句：「今天加班到九点，累死了」
- 他想要的不是推荐，是**有人接一句话**
- 他会为什么转发：**"这就是我"** 的精准命中感

### 画像 B · 小林（次核心，情绪向内容的主力受众）

- 25 岁，内容运营，上海，合租
- 内耗型：白天对着人笑一天，晚上一句话都不想说
- 一个人吃饭时常常在刷短视频，**不是因为想看，是因为安静太吵**
- 触发语句：「今天不太想说话，但也不想一个人」
- 她会为什么转发：**"被理解了"** + 画面好看可发朋友圈

### 画像 C · 老陈（外围，技术向内容的受众）

- 32 岁，产品经理，常年出差
- 在陌生城市的酒店里点外卖，是常态
- 他会为什么转发：**技术实现**（MCP tool-calling + 本地语音）+ 真实下单闭环

### 6.1 ⚠️ 两种受众要分开

| | 使用受众（A/B） | 传播受众（C + 开发者） |
| --- | --- | --- |
| 关心什么 | **感受** | **怎么做的** |
| 看什么物料 | 30s 情绪向宣传片、小红书图文 | 技术长文、Demo 视频、仓库 |
| 转化目标 | 共情 → 转发 | 认可 → Star |

> **引流宣传片只服务"使用受众"。** 技术亮点在片子里最多出现一个镜头，
> 讲多了会把情绪节奏打断——技术叙事交给 Demo 视频和技术长文。

## 7. 引流宣传片素材包（**交接给编导/AI 视频站的全部输入**）

### 7.1 主题方向（三选一，**推荐 B**）

| 选项 | 主题 | 一句话 | 适用 |
| --- | --- | --- | --- |
| A | 效率向 | "一句话，饭就点好了" | ❌ **不建议**：撞进点餐助手红海，浪费差异化 |
| **B** | **情绪向（推荐）** | **"一个人吃饭，难的从来不是饭"** | ✅ 30s 宣传片 / 小红书 / 视频号 |
| C | 技术向 | "我用麦当劳 MCP 做了个饭搭子" | ✅ 但只给 B 站 / 掘金，不给情绪平台 |

### 7.2 叙事重点

**全片只讲一件事**：`孤独 → 被接住`。

- **一句话主题**：一个人吃饭，难的从来不是饭，是没人说话。
- **三幕结构**：
  1. **建立**（0–12s）：深夜、一个人、一顿饭。**不给解决方案，只给处境**
  2. **转折**（12–23s）：桌上亮起一小片光 → 它说话了，而且记得你
  3. **收束**（23–30s）：他松下来了。**答案不是"饭更好吃"，是"这顿饭不孤单"**
- **必须出现的一个细节**：**对面那把空椅子**（全片情绪支点）
- **绝对不能出现**：产品功能罗列、参数、架构图、Logo 特写

### 7.3 推荐时长与节奏

**标准版 30 秒 / 7 个镜头 / 16:9 1920×1080**

| 时间 | 时长 | 画面 | 旁白 | 情绪 |
| --- | --- | --- | --- | --- |
| 00:00–00:03.5 | 3.5s | 深夜写字楼，一个背影走出旋转门 | **（留白，只有环境音）** | 起 |
| 00:03.5–00:07 | 3.5s | 快餐店窗外，玻璃透出暖光，他推门进去 | 「晚上九点，又是一个人。」 | 沉 |
| 00:07–00:12 | 5.0s | 餐盘特写缓推，**对面椅子空着** | 「一个人吃饭，难的从来都不是饭。」「是没人说话。」 | **最低点** |
| 00:12–00:16 | 4.0s | 手机在桌上亮起，琥珀光映在桌面 | **（留白）** | **转折** |
| 00:16–00:23 | 7.0s | **真实产品界面**：记忆 → 算价 → 订单卡 | 「所以我们做了个饭搭子。」「它记得你上次点了什么，报价一分不差。」 | 回升 |
| 00:23–00:26.5 | 3.5s | 侧脸低头看屏幕，肩膀松下，微微笑 | 「帮你把单下好，陪你把这顿吃完。」 | 暖 |
| 00:26.5–00:30 | 3.5s | 品牌卡 + Slogan + CTA | 「一个人吃饭，但不孤单。」 | 收 |

**节奏三条硬指标**

1. **前 3.5 秒零旁白**——让观众先进入这个夜晚，别急着解释
2. **旁白总量 ≤ 90 字**，句间留 ≥ 0.4s。30 秒里**至少留 10 秒纯画面呼吸**
3. **镜 3 是情绪最低点，镜 4 是转折点**。这两个点的位置不能挪——挪了整个情绪弧就塌了

### 7.4 镜头 / 画面要点

**分镜骨架**（详细提示词与运镜见 `docs/design/VIDEO_PROMPTS-30s.txt`）

| 镜 | 画面要点 | 运镜 | 素材来源 |
| --- | --- | --- | --- |
| 1 | 背影走出写字楼；冷蓝夜 + 一盏暖黄路灯勾肩线 | 固定 + 极缓推 3% | AI 生成 |
| 2 | 店内暖光透出玻璃，冷暖强对比 | 极缓横移 | AI 生成 |
| 3 | 单人餐盘 + **对面空椅子**；暖黄顶光，热气微升 | 缓推向下的俯角 | AI 生成 |
| 4 | 手机正面朝上，屏幕刚亮，琥珀光投在木纹上；手指入镜 | **固定机位**，只让光变化 | AI 生成 |
| 5 | **真实产品界面**三连：记忆 → ¥33.5 → 订单卡「待支付」 | 每段缓放大 8%，6 帧溶解 | **真实截图，不用 AI** |
| 6 | 侧后四分之三，低头看屏；屏幕冷光 + 餐厅暖光夹脸 | 固定 + 极缓推 | AI 生成 |
| 7 | 品牌卡：光团子淡入 → 标题 → Slogan → CTA | 底图缓推 5% | 代码渲染 |

**画面规范的六条硬约束**

1. **冷暖对撞**：阴影走冷蓝紫，高光走暖琥珀——这是全片的视觉签名
2. **统一调色**：色温 +6 / 对比 +8 / 高光 −10 / 阴影 +5，全片一致
3. **统一颗粒**：加 15–20 强度胶片颗粒，**压掉 AI 的"干净感"穿帮**
4. **统一暗角**：收拢视线，也让画面更像"深夜里的一个小角落"
5. **运镜只准"轻"**：缓推、横移、固定微动。**禁止环绕、快速跟拍、手持甩镜**（AI 必崩）
6. **镜 5 保持界面原生深色，不加任何滤镜**——这一镜的任务是"真"，不是"美"

**镜头禁忌**

- ❌ 品牌 Logo / 金色拱门 / 可读品牌文字 / 带商标包装
- ❌ 清晰正脸直视镜头（既规避 AI 人脸崩坏，也免肖像问题）
- ❌ 手部大特写且动作复杂（AI 视频最易崩的第二名）
- ❌ 大笑、夸张表情、比手势
- ❌ 医院、药、体重秤、健身器材（会被读成"健康焦虑"，触发合规风险）

### 7.5 文案基调

**旁白全文（女声，温和不甜腻，语速 4.2–4.5 字/秒）**

> 00:03.5　晚上九点，又是一个人。
> 00:07.0　一个人吃饭，难的从来都不是饭。
> 00:10.5　是没人说话。
> 00:16.0　所以我们做了个饭搭子。
> 00:18.5　它记得你上次点了什么，报价一分不差。
> 00:23.0　帮你把单下好，陪你把这顿吃完。
> 00:27.0　一个人吃饭，但不孤单。

共 **87 字**。**句子短、口语、不加形容词。**

**三种可选的旁白写法**（供编导换）

- 递进式（推荐，即上表）：从"处境"推到"被接住"
- 独白式：全部改成第一人称内心独白（「又是九点。」「算了，随便吃点。」）
- 反问式：「一个人吃饭的时候，你都在想什么？」→ 结尾「不用想了，有人陪你吃。」

**语气样例（可直接用作社交平台配文）**

- ✅「它记得你上次点了什么。就这一点，够了。」
- ✅「不是让你吃得更快，是让你一个人吃的时候，没那么安静。」
- ❌「从此告别一个人吃饭的孤独！」（太满、像广告）
- ❌「一个人吃饭太惨了，快来找 AI 陪你」（卖惨，且贬低了用户的处境）

**字幕规则**：位置在**底部安全区上方 12%**；字号 42–46；白色 + 30% 黑描边；竖版放到 18%。
